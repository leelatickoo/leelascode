### Running Code

| Shortcut | Action |
|---|---|
| `Cmd + Return` | Run current line / selection |
| `Option + Return` | Run current line / selection, keep cursor in place |
| `Cmd + Shift + S` | Source the current document |
| `Cmd + Shift + Return` | Source the current document (with echo) |
| `Cmd + Option + R` | Run the entire current document |
| `Cmd + Option + P` | Re-run the previous code region |
| `Esc` | Interrupt the currently executing command |

### Editing

| Shortcut | Action |
|---|---|
| `Option + -` | Insert assignment operator `<-` |
| `Cmd + Shift + M` | Insert pipe operator `\|>` / `%>%` |
| `Cmd + Shift + C` | Comment / uncomment current line or selection |
| `Cmd + I` | Reindent selected lines |
| `Cmd + Shift + A` | Reformat selection |
| `Option + Up / Down` | Move current line(s) up or down |
| `Cmd + Z` / `Cmd + Shift + Z` | Undo / Redo |

### Navigation &amp; Find

| Shortcut | Action |
|---|---|
| `Ctrl + .` | Go to file / function |
| `Cmd + F` | Find and replace (in current document) |
| `Cmd + Shift + F` | Find in files (whole project) |
| `Cmd + G` / `Cmd + Shift + G` | Find next / previous match |
| `Ctrl + P` | Jump to matching brace / parenthesis |

### Console &amp; Panes

| Shortcut | Action |
|---|---|
| `Ctrl + 1` | Move focus to the Source editor |
| `Ctrl + 2` | Move focus to the Console |
| `Ctrl + L` | Clear the console |
| `Cmd + Up` | Pop up console command history |

### Documents &amp; Session

| Shortcut | Action |
|---|---|
| `Cmd + S` | Save the active document |
| `Cmd + Shift + N` | New R script |
| `Cmd + Shift + K` | Knit / render the current document |
| `Cmd + Shift + P` | Show the command palette |
| `Cmd + Shift + F10` | Restart the R session |
